送信経路の決定ルール

  • 「有効」にできるリレーは 常に1件のみ です (別の行を有効にすると、それまで有効だった行は自動で無効になります)
  • 有効な行が 1件 ある場合 → その行経由で送信
    • 有効リレーのIPが (HTTP-bridge転送機) と一致 → SSH+HTTP API 方式
    • それ以外のIP (例: AMG 157.7.89.36) → 直接 SMTP で配送
  • すべて無効 の場合 → 本サーバの postfix から直接配信 (avu74g.jp ドメインで MX ルックアップ)
