設定

リレーサーバー設定

送信に使用するリレーサーバーの接続情報 (名前・IP・ポート) を管理します。

登録数: 0

定型文

個別送信、一斉送信、返信画面で再利用する件名・本文をあらかじめ登録できます (最大50件)。

登録数: 0 / 50

返信画面設定

返信ページの共通ヘッダー・フッター・CSSをTinyMCEで編集します。

フォルダ設定

ユーザーのグルーピングに使うフォルダ名・個数を管理します。

ドメイン設定

返信URLと送信元ドメインを設定します。ワイルドカードドメイン + ランダム文字列に対応。

外部リンクドメイン生成

メール・SMS送信時の短縮URL用ドメインを複数登録し、使用中のドメインを切り替えます。クリックでユーザーの最終ログインを記録。

登録数: 0

本ドメイン表示設定

本ドメイントップ (/) に表示するHTMLを3パターン保存し、チェックで切替できます。 未設定の場合は管理画面ログインへリダイレクトされます。

送信者名設定

送信メールの From ヘッダの表示名を制御します。固定・30件リストからランダム・ランダム英数字生成のフィルタリング対策。

管理者パスワード変更

現在ログインしている管理者アカウントのパスワードを変更します。初期パスワード (admin123) のままでは運用しないでください。

操作ログ

ログイン、管理者パスワード変更、データ更新などの操作履歴を確認できます。

IMAP 監視同期

SoftBank キャリアアドレスの IMAP 受信監視リストを、キャリア登録割り当ての現状と同期します (通常は自動・手動再生成も可)。

SMS配信設定

BytePlus SMS OpenAPI (Basic認証) の Username / Password、送信者名、ローカル配信の設定を管理します。
