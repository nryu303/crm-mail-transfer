返信画面設定

専用返信画面HTML 一括編集 設定に戻る

ここで設定した内容は、ユーザー宛の返信ページ (/reply/{token}) 全体の共通ヘッダーとフッター、追加CSSとして適用されます。 各ユーザーのメモ欄が空の場合はここで設定したヘッダーが使われます。

HTMLは生のまま入力してください。 右側のプレビューは入力中に自動更新されます (保存前の見た目確認用)。

返信ページの上部に表示されるHTML。画像、装飾タグ、リンクが使えます。

▶ ヘッダー プレビュー (sandboxed iframe — 上下スクロール可)

オフにすると、返信ページ (/reply/{token}) 上でヘッダー部分自体が表示されなくなります（このプレビュー欄は編集用に常時表示されます）。

ここに入力したHTMLが、返信ページ (/reply/{token}) の一番下・本文入力フォームより後ろに、 そのまま挿入されます。右側の「▶ フッター プレビュー」に入力内容がリアルタイムで反映されます。

入力例: <p style="text-align:center;color:#94a3b8;font-size:12px;">お問い合わせは上記フォームよりお願いいたします</p> のように書くと、右側プレビューのように中央寄せ・グレー文字の一行が表示されます。

▶ フッター プレビュー

左のHTMLを入力すると、実際に返信ページの下部に表示される見た目がここに反映されます。

ここに入力したCSSが、返信ページ全体（上のヘッダーHTML・本文フォーム・フッターHTMLすべて）に適用されます。 通常のCSS構文（セレクタ { プロパティ: 値; }）で記述してください。右側のプレビューに即座に反映されます。

入力例: .reply-banner { background: #003366; color: #fff; } のように、 対象にしたい要素のクラス名（返信ページのHTML内で使われているもの）を左に、変更したいスタイルを { } の中に書きます。 どの要素がどんなクラス名かは、上の「共通ヘッダーHTML」に自分で入れたタグ、または開発担当にご確認ください。

※このオン/オフ/表示しないは、あくまでこの設定画面内のプレビュー欄の見え方です。ユーザー側の返信ページに表示される本文入力フォーム自体を消したい場合は、下の「本文入力フォームをユーザー側に表示する」を使用してください。

オフにすると、返信ページ (/reply/{token}) から件名・本文の入力欄と送信ボタンが消えます。 上のヘッダー表示と両方オフにした場合、返信ページにはメッセージボックスのみが表示されます。

%reply_url% / %external_url% を含めて送信するメッセージ（個別送信・一斉送信いずれも）で、 URLの直上に改行して自動的に挿入されます（空欄の場合は改行のみ）。 この項目はメッセージスレッド画面・一斉送信画面からも同じ内容を保存・編集できます。
